# 云购生活 · 第 4 周部署手册

> 主题：可视化（Superset + ECharts）· 项目部署（Docker Compose）
> 作者：张宇（20230308059）｜ ydsh-team

## 一、系统架构

```
┌────────────── 一键编排 docker compose up -d ──────────────┐
│                                                           │
│  mysql(3307) ──> hive-metastore(9083) ──> hive-server(10000)│
│      │                                        │           │
│  元数据/业务库 ydsh_ads                 数仓 ORC 数据       │
│      │                    (命名卷 hive-warehouse 持久化)   │
│      ↓                                        ↓           │
│  superset(8088) <──────── 数据源 JDBC ────────┘           │
│  app/streamlit(8501) ──> NL2SQL(智谱GLM) ──> hive-server   │
└───────────────────────────────────────────────────────────┘
```

## 二、一键部署步骤

### 1. 准备密钥
```bash
cp .env.example .env
# 编辑 .env：ZHIPU_API_KEY 必填；其余有默认值
```

### 2. 启动全部服务
```bash
docker compose up -d
docker compose ps        # 等待 hive-server 变为 healthy（约 1-2 分钟）
```

### 3. 初始化数据（仅首次）
```bash
docker cp sql/../../ydsh-week1/data/ods_*.csv ydsh-hiveserver2:/data/ 2>/dev/null || true
bash sql/replay_all.sh            # ODS→清洗→DWD→DWS→ADS 全链路重放（约8分钟）
python sql/load_mysql.py          # ADS 指标导入 MySQL 业务库 ydsh_ads
```
数据写入命名卷 `hive-warehouse`，**此后重建容器不再丢失**。

### 4. 注册 Superset 数据源与图表（仅首次）
```bash
python sql/superset_setup.py      # 注册 ydsh_hive / ydsh_mysql 数据源
python sql/superset_charts.py     # 创建 7 个数据集、6 个图表并组装仪表板
```

### 5. 访问验证
| 服务 | 地址 | 验证标准 |
|---|---|---|
| Superset 仪表板 | http://localhost:8088 （admin/admin） | 仪表板"云购生活经营分析仪表板"6 个图表有数据 |
| Streamlit 问答 | http://localhost:8501 | 输入"销量最高的前5个品类"返回 SQL+结果 |
| HiveServer2 | jdbc:hive2://localhost:10000 | beeline 连接并查询 dwd_order 计数 |
| MySQL 业务库 | 127.0.0.1:3307 (root) | ydsh_ads 库 7 张表 |

## 三、服务依赖与健康检查

- `hive-metastore` depends_on `mysql: service_healthy`（元数据库就绪才启动）
- `hive-server` 自带 healthcheck（beeline SELECT 1，start_period 90s）
- `superset` / `app` depends_on `hive-server: service_healthy`，保证查询服务就绪后才启动
- 数仓数据放命名卷 `hive-warehouse`，避免容器重建丢数据（第 3 周踩坑经验）

## 四、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| hive-server 反复退出 | metastore 未就绪 | `docker compose restart hive-server` |
| Superset 连不上 Hive | 容器网络/驱动 | 确认在同一 compose 网络；容器内已装 pyhive |
| MySQL 图表报 MySQLdb | 驱动映射 | 本方案已内置 sitecustomize（pymysql 伪装 MySQLdb） |
| 问答 401 | Key 错误 | 检查 .env 的 ZHIPU_API_KEY 是否完整（含点号后段） |
| 图表无数据 | 数据未初始化 | 执行第 3 步初始化 |
